# Security policy

byterefs is primarily a specification, but the specification describes how
software should locate and read bytes from remote and local storage. Issues
that could lead an implementation to read outside intended byte ranges, follow
unexpected locations, or exhaust resources are security relevant.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub private vulnerability reporting ("Report a vulnerability" under the
Security tab of the affected repository), or contact the maintainers at:
mdsumner@gmail.com

Include a description of the problem, the affected repository or part of the
specification, and steps or an example to reproduce it. We aim to acknowledge
reports within a week.
