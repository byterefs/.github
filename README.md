# byterefs/.github

Organization-wide defaults for the byterefs GitHub organization.

- `profile/README.md` is shown on the organization page (https://github.com/byterefs).
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`,
  `ISSUE_TEMPLATE/` and `pull_request_template.md` apply to every repository
  in the organization that does not provide its own copy.

Edit files here to change the defaults everywhere.
